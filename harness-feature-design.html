05 / 架构与数据

插件扩展 · 单一事实来源 · 无需另起一套 Agent Loop

展示功能先使用已有 Session 记录构建投影；只有确实需要跨重启保留的用户决定才新增数据。新的服务必须同时设计服务定义、具体实现和实际消费者。

01 / CLIENT

工作台与详情

通过现有 Conversation、Sidebar 和 Settings 扩展点接入。失败诊断放在 Trajectory 旁，验收跟随任务，环境检查跟随工作区。

  • 共享状态由注册的 store 管理。
  • 派生视图不持有另一份日志。
  • 中英文文案使用类型化字典。
02 / HOST

查询、策略与执行

复用 sessionQuery、sessionProjections、commands、goals、tools 和 subprocess。资源准入策略在实际发起请求的扩展点执行。

  • 路由验证 Session 访问范围。
  • 用户操作采用修订号拒绝旧写入。
  • 效果注册可卸载，取消等待清理。
03 / DURABILITY

事实、引用与内容

会话事实追加日志；书签与配方使用工作区存储；大体积文件内容由独立存储实现保存，日志只引用内容摘要与清单。

  • 引用使用品牌化 ID 与逻辑事件 seq。
  • 既有持久化代际保持不可变。
  • 丢失内容展示不可用，不伪造快照。

记录事实与诊断推断分开

退出码、工具结果和文件摘要属于已记录事实；错误原因属于推断。诊断建议始终附事件引用。仅有时间相邻的事件不能被标成确定因果。

模型可见输入必须可重建

把验收标准、配方或上下文选择交给模型时，使用已有可记录输入路径或新增有所有者的 Session 事件。UI 的本地状态不能暗中改变请求。

恢复会话不等于恢复文件或重做操作

F05 首版只比较；Session fork 不承诺隔离或回滚文件系统。F02 首版只保存与审阅，不执行自动恢复。未来工作树隔离需单独设计。

未测得与零值分开

缺失 Token、未知价格、未运行检查和已过期结果均有独立状态。费用为带价格版本的估算，账单与供应商配额仍由供应商确认。

建议数据职责与持久化审阅点
职责建议记录一致性与兼容性
事件引用SessionId + 逻辑 seq + 可选工具调用身份；资源导航参数。分叉不能沿用父会话地址；旧页按目标 seq 加载，访问拒绝不泄露内容。
验收证据验收项版本、执行结果引用、argv / cwd、验证范围与内容摘要。事实追加；旧执行永远保留；当前状态通过修订与范围重算。
变更留存不可变的文件内容对象和 manifest；记录缺失、过大与二进制状态。对象先写入并校验，再发布 manifest 引用；配额与清理要显式可配。
预算策略规则版本、准入 / 停止决定、结算引用、作用范围。同一用量只计一次；状态恢复与授权恢复分开；进程丢失的用量标未知。
用户偏好书签、配方定义、UI 视图选项存于所属工作区或设置。非模型事实无需复制进 Session；一旦作为模型输入使用，记录实际解析结果。

以上是概念设计，不是已经发布的类型或事件名。实现时必须完成 persistence-type acknowledgement；只有结构性格式变化才按现有规则决定版本迁移，SQLite schema 保持单调递增。

06 / 验收与依据

先建立基线，再评估收益

功能必须通过的场景

  • 历史分页未加载、连接替换、重启及事件不可见时，定位结果明确。
  • 验收结果在文件修改后过期；人工确认与程序验证不混为一谈。
  • 同一结果重复到达不重复计费；达到预算后停止新请求，正确呈现在途结算。
  • 插件卸载释放注册、订阅与资源；功能可从组合中移除。

验证证据

  • 纯模型单测覆盖状态转换和拒绝路径。
  • 通过真实 dsh profile 的 keyless Session replay 验证模型输入与持久化。
  • 浏览器验证跨页定位、键盘操作、窄屏布局和重连。
  • Session 事件或生命周期改变时，同步两种 SDK 的预期输出。

落地后的衡量方式

先记录当前版本的固定任务基线；上线后用相同任务比较。报告中不预设“提升百分比”。

  • 从失败提示到打开错误输入的操作次数与用时。
  • 交付时仍缺证据、或证据过期的验收项比例。
  • 预算达到后额外准入的请求数与在途结算量。
  • 已保存对比内容在重启后的读取成功率。

本次暂不扩张的范围

多租户组织管理、云端插件市场、自动 PR 合并、任意副作用重放、工作区一键回滚不列入本轮。当前最有价值的投入，是让已有执行能力更容易理解、验证和复用。

已有实验性 Agent Teams、自动审批等功能继续按其现有定位使用；不把它们重新包装成新能力。

Workspace：会话搜索与导航
